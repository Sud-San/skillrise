🔧 TROUBLESHOOTING - 404 ERRORS FOR CSS/JS FILES
================================================

If you're getting 404 errors for style.css or main.js, here's how to fix it:

PROBLEM: 404 Not Found for css/style.css and js/main.js
========================================================

This means the server can't find the files. This happens when:
1. You're running the server from the WRONG DIRECTORY
2. The file structure is incorrect


SOLUTION 1: Make Sure You're in the Right Directory
====================================================

❌ WRONG:
---------
cd Desktop
php -S localhost:8000
# Then trying to open: http://localhost:8000/codearena/

✅ CORRECT:
-----------
cd Desktop/codearena
php -S localhost:8000
# Then open: http://localhost:8000


EASY WAY - Use the Start Scripts:
==================================

For WINDOWS:
-----------
1. Open Command Prompt
2. Navigate to codearena folder:
   cd C:\Users\YourName\Desktop\codearena
3. Run:
   start-server.bat

For MAC/LINUX:
--------------
1. Open Terminal
2. Navigate to codearena folder:
   cd ~/Desktop/codearena
3. Make script executable:
   chmod +x start-server.sh
4. Run:
   ./start-server.sh


VERIFY YOUR FILE STRUCTURE:
============================

Your codearena folder should look like this:

codearena/
├── index.html              ← Must be at ROOT level
├── games.html
├── leaderboard.html
├── profile.html
├── css/
│   └── style.css          ← Inside css folder
├── js/
│   └── main.js            ← Inside js folder
├── games/
│   ├── debugging-master.html
│   └── ...
├── php/
├── config/
└── database.sql


HOW TO TEST IF IT'S WORKING:
=============================

1. Start the server from INSIDE codearena folder
2. Open: http://localhost:8000
3. Open browser console (Press F12)
4. You should see NO 404 errors
5. You should see the dark blue theme

If you see 404 errors:
- Check you're in the codearena folder when running the server
- Type 'pwd' (Mac/Linux) or 'cd' (Windows) to see current directory
- You should be IN the codearena folder, not above it


MANUAL CHECK:
=============

Try accessing the CSS file directly:
http://localhost:8000/css/style.css

If this shows CSS code → Server is working correctly
If this shows 404 → You're in the wrong directory


STILL NOT WORKING?
==================

Try this step-by-step:

1. Close any running servers (Ctrl+C in terminal)

2. Find where codearena folder is:
   - Is it on Desktop?
   - In Downloads?
   - Write down the full path

3. Open fresh terminal/command prompt

4. Navigate to codearena:
   cd /full/path/to/codearena
   
   Example:
   cd C:\Users\John\Desktop\codearena  (Windows)
   cd ~/Desktop/codearena              (Mac/Linux)

5. Verify you're in the right place:
   - Windows: dir
   - Mac/Linux: ls
   
   You should see: index.html, css, js, games folders

6. Start server:
   php -S localhost:8000

7. Open browser:
   http://localhost:8000

8. Check browser console (F12) for errors


ALTERNATIVE - Use Python Instead:
==================================

If PHP isn't working, try Python:

cd /path/to/codearena
python -m http.server 8000

Then open: http://localhost:8000
