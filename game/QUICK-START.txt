⚡ CODEZY - QUICK START GUIDE
=============================

🎮 WHAT IS CODEZY?
==================
Codezy is a professional, dark-blue themed interactive coding games platform 
with 7 unique games designed to teach programming through play.

🚀 HOW TO RUN
=============

STEP 1: Navigate to Codezy folder
----------------------------------
cd path/to/codezy

STEP 2: Start a web server
---------------------------
Choose ONE of these options:

OPTION A - PHP (Recommended):
    php -S localhost:8000

OPTION B - Python:
    python -m http.server 8000

OPTION C - XAMPP:
    1. Copy codezy folder to htdocs/
    2. Start Apache in XAMPP
    3. Open http://localhost/codezy/

STEP 3: Open in Browser
------------------------
http://localhost:8000

🔧 REUSABLE COMPONENTS
======================
All games use these classes from main.js:

1. GameTimer - Countdown timers
2. ScoreManager - Points, streaks, multipliers
3. ProgressTracker - Completion tracking
4. UIFeedback - Notifications, confetti
5. GameSession - Save/load game data
6. Utils - Helper functions

📊 GAME PAGE STRUCTURE
======================
Every game follows this consistent layout:

1. Header (Title + Description)
2. Progress Bar (Timer, Score, Streak, %)
3. Main Game Area (Challenge + Code + Answers)
4. Result Modal (Score, Accuracy, Time, Buttons)

All use the same CSS classes and JavaScript patterns.

💡 CUSTOMIZATION
================
Want to change colors?
→ Edit :root variables in css/style.css

Want to add a game?
→ Copy any game HTML, update content, maintain UI structure

Want to modify difficulty?
→ Edit challenges array in each game's JS file
